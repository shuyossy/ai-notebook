# information.json 記載方法

## 概要
このファイルはAIKATAアプリのお知らせ配信に使用されます。
アプリ起動時にこのファイルを読み込み、お知らせをユーザーに表示します。

## 環境について
- **開発環境**: このローカルファイル (`information/information.json`) が読み込まれます
- **本番環境**: GitLabリポジトリに配置された `information.json` が読み込まれます

## ファイル形式
JSONファイルとして、以下の形式で記載します。

```json
{
  "informations": [
    {
      "id": "一意の識別子",
      "message": "お知らせ本文",
      "order": 表示順
    }
  ]
}
```

## フィールド説明

| フィールド | 型 | 必須 | 説明 |
|-----------|------|------|------|
| informations | array | Yes | お知らせ情報の配列 |
| informations[].id | string | Yes | お知らせの一意識別子（重複不可） |
| informations[].message | string | Yes | お知らせ本文（改行は `\n` で表現） |
| informations[].order | number | Yes | 表示順（小さい数字が上に表示、整数のみ） |

## 記載例

### 単一のお知らせ
```json
{
  "informations": [
    {
      "id": "maintenance-20260107",
      "message": "【メンテナンス予定】\n2026年1月10日 10:00〜12:00にメンテナンスを実施します。",
      "order": 1
    }
  ]
}
```

### 複数のお知らせ
```json
{
  "informations": [
    {
      "id": "urgent-notice",
      "message": "【重要】システムに関する重要なお知らせです。",
      "order": 1
    },
    {
      "id": "update-v1.2.0",
      "message": "バージョン1.2.0がリリースされました。\n新機能の詳細は公式サイトをご確認ください。",
      "order": 2
    },
    {
      "id": "event-info",
      "message": "年末年始の営業についてのご案内です。",
      "order": 3
    }
  ]
}
```

### お知らせを非表示にする（空配列）
```json
{
  "informations": []
}
```

## 注意事項

1. **id の一意性**: 各お知らせの `id` は重複しないようにしてください
2. **order の順序**: `order` の値が小さいほど画面の上に表示されます
3. **改行の記載**: 改行は `\n` を使用してください（JSONの仕様）
4. **JSON の妥当性**: ファイル保存前にJSON形式が正しいか確認してください
5. **文字コード**: UTF-8で保存してください

## お知らせの表示について

- お知らせはアプリのメインコンテンツエリア上部にバナー形式で表示されます
- ユーザーは×ボタンでお知らせを閉じることができます
- 閉じたお知らせはアプリを再起動すると再度表示されます
- お知らせの取得に失敗した場合、エラーは表示されずお知らせが非表示になります
