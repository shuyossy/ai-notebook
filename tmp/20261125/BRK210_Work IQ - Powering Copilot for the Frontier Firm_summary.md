# 要約

本セッションは、Microsoft 365 Copilot（以下 Copilot）の裏側で動く「Work IQ」について、その役割と Ignite 2026 での機能強化を解説したものである。

## Work IQ とは何か／扱うデータの規模

- Work IQ は、Copilot の裏側で動いている仕組みである。メール・チャット・会議・ファイルなど Microsoft 365 上の情報から、個人・チーム・会社の「仕事の文脈（コンテキスト）」をつかみ、Copilot に渡す役割を持つ。
- どの会社も同じ AI モデルを使える時代には、AI の賢さそのものより「その会社の仕事の文脈をどれだけ知っているか」で差がつく、というのがセッションの主張である。
- Microsoft 365 では毎週、Teams のメッセージが約150億件、メールが900億件以上、新しいファイルが100億件以上生まれている。Work IQ は、メールの受信やファイルの更新があるたびに、全体を作り直さずに必要な部分だけ情報を更新できる。

## コンテキストにどのような情報を含めるか

- Work IQ は、メール・会議・チャット・ファイル・顧客管理システム・社員情報などから、質問に必要な情報だけを選んで AI に渡す。AI はそれをもとに考えて答える、という分担になっている。
- 選ばれる情報は、質問した本人が普段から閲覧できる範囲のものだけである。本人に閲覧権限のない情報が使われることはない。

## Work IQ の全体像：Memory・Context・Skills

- 材料になるのは、Microsoft 365 のデータ、Dynamics 365（営業・顧客管理などの業務システム）や Power Platformのデータ、外部サービスのデータの3つである。
- Work IQ はこれらを次の3つの役割で使う。
  - Memory（記憶）：使う人の好みや過去のやり取りを覚える
  - Context（文脈）：仕事の内容・人・組織のつながりを把握する
  - Skills（スキル）：決まった作業を成果物に仕上げる
- その結果を、Copilot や Copilot Studio、各社が独自に作る AI エージェントで使う。

## Memory

- 従来からある「Copilot への指示の登録」や「覚えてほしいことの保存」に加え、過去のチャットからも自動で学ぶようになった。
- 回答のどこに記憶が使われたかを確認でき、不要な記憶は削除できる（2026年10月に正式提供）。
- Ignite 当日から、本人のメールの書き方（文体、箇条書きの好み、相手による書き分け）を学ぶ機能の正式提供が始まった。Word や PowerPoint など他のアプリでも本人の好みを引き継ぐ機能も、順次正式提供される。これにより、下書きが最初から「本人らしい」形で出てくる。

## Context：仕事・人・組織

- これまでは、Teams・Outlook・会議の文字起こし・Office 文書といった「仕事の中身」の情報が中心だった。
- Ignite では、「人」と「組織」の情報の強化が発表された。たとえば「セキュリティのルールについて誰に相談すればいい？」と聞くと、詳しい社員を紹介してくれる。「部署のどこに AI の専門スキルを持つ人が足りないか」を分析したり、組織構成を分析する画面を作ったりもできる。

## Skills

- 週次の状況報告や顧客向け資料など、決まった手順の作業を「スキル」として登録できる。一度登録すれば、さまざまな Copilot の画面から同じように呼び出せる。

## Dynamics 365／Power Platform と外部サービスとの連携

- Dynamics 365 と Power Platform のデータを、Work IQ で正式に使えるようになった。データを移さずに、メールや会議の情報と合わせて活用できる。
- 外部サービスとの連携機能（コネクタ）は350種類以上あり、前日に公開された Copilot 用の拡張機能カタログから追加できる。連携の方式は次の2つである。
  - その都度、相手先のシステムに最新の情報を取りに行く方式
  - あらかじめ情報を取り込み、すばやく検索できるよう整理しておく方式
- たとえば ServiceNow（IT サービス管理ツール）や Jira（課題管理ツール）と連携すると、障害状況の確認やチケットの対応を Copilot 上から直接行える。

## Agent 365 によるアプリの管理

- Copilot で作られたアプリは、AI エージェントやアプリをまとめて管理する Agent 365 で管理できる。Microsoft 365 の管理画面に、社内のアプリを一覧できる画面が追加された。
- アプリごとに、作成者、公開状況、利用状況、正常に動いているか、どの外部サービスとつながっているかを確認できる。

## AI エージェントにも新入社員と同じ前提知識を

- 新入社員に仕事を任せるには、①所属チーム・役割・仕事の進め方、②会社で今何が進んでいるか、③社内ルールや手順書などの蓄積された知識、の3つを教える必要がある。AI エージェントにも同じ3つが必要である。
- Microsoft 365 はこれまで「人と人が一緒に働く場」だったが、今後は「人と AI エージェントが並んで働き、情報を共有する場」になっていく。

# 所感

- 「どの AI を使うか」より「AI に自社の情報をどれだけ渡せるか」で成果が変わる、というメッセージが一貫していた。Copilot がどれだけ役に立つかは、会議の記録や Teams でのやり取り、組織の情報が Microsoft 365 上にどれだけそろっているかに大きく左右される。社内の情報を Microsoft 365 に集める運用や、社員の上司・部署・スキルといった情報を正しく登録しておくことが前提になると考えられる。
- Work IQ は「その人が閲覧できる情報だけを使う」仕組みのため、本来見せるべきでない人にまで共有されているファイルやサイトは、そのまま Copilot の回答に使われてしまう。導入前に、SharePoint や OneDrive の共有範囲・閲覧権限を見直しておくことが引き続き重要だと感じた。
